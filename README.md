# Учёт обходов: как выложить на GitHub Pages

1. Зайдите на github.com и войдите (или зарегистрируйтесь).
2. Нажмите **New repository**. Название, например, `obhody`. Поставьте **Public**. Нажмите **Create repository**.
3. Нажмите **uploading an existing file** и перетащите файл **index.html**. Внизу нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В «Branch» выберите **main** и папку **/(root)**, нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/obhody/`.

## Первый запуск
1. Откройте сайт → **Настройки → Загрузить из Excel** → выберите ЦАП_УКА_ИЮНЬ.xlsx. Адреса и хантеры загрузятся.
2. На вкладке **Адреса** выберите адрес, хантера и дату, нажмите **Сохранить обход**.

## Важно
- Данные хранятся в браузере на том устройстве, где вы работаете. На другом телефоне или компьютере будет пусто.
- Раз в неделю делайте **Настройки → Скачать копию**. Из неё можно восстановить данные.
- Репозиторий публичный, но данные в нём не хранятся: в файле только программа, адреса остаются у вас в браузере.
