# Железный месяц

Сайт-трекер: программа тренировок на похудение и рост силы.

- план на 4 недели, 3 тренировки в неделю по 60 минут
- цель по весу (начальный и целевой вес, темп, прогресс)
- силовые показатели с расчётным максимумом (формула Эпли)
- вес, мышечная масса, талия
- КБЖУ: автоматическая норма, база продуктов, дневник питания, пример рациона

Один файл `index.html`, без сборки и зависимостей. Данные хранятся в браузере (localStorage).

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.

## Источники
ExRx.net, wger.de, ВОЗ (физическая активность), формула Миффлина — Сан-Жеора, формула Эпли.

Расчёты ориентировочные и не заменяют консультацию врача.
